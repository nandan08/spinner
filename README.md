# Winner Picker Wheel — GitHub Pages

## English

A standalone, bilingual Arabic/English random-name wheel with Nandan Pixel branding. The app starts in Arabic. Use the language button at the top to switch the entire interface between Arabic (right-to-left) and English (left-to-right). Switching languages does not change or remove the names you entered.

### Use the wheel

- Type or paste names in the list, one name per line, or add a name with the input field.
- Select **Spin the wheel** to pick a winner.
- Optionally remove each winner from future draws.
- Winner names keep the exact spelling and script entered. They are never translated or modified.

No names are preloaded. Names stay in the open page only; they are not sent to a server and are cleared when the page is refreshed or closed. The app has no external dependencies.

### Publish with GitHub Pages

1. Add `index.html`, the `assets/` folder, and `.nojekyll` to the repository root. Alternatively, put them in `docs/` if Pages is configured to publish from that folder.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` (or `/docs` if you used `docs/`), then save.
4. Open the Pages URL shown by GitHub. It usually looks like `https://USERNAME.github.io/REPOSITORY/`.

If publishing from the repository root, upload the contents of this package so `index.html` is at the root—not nested inside the `github-pages-wheel` folder. The ZIP contains that folder for convenience; unzip it and copy its contents. GitHub Pages provides the public HTTPS link after deployment.

## العربية

تطبيق مستقل لاختيار اسم عشوائي، بواجهتين عربية وإنجليزية وهوية Nandan Pixel. يبدأ التطبيق بالعربية. استخدم زر اللغة أعلى الصفحة للتبديل بين العربية (من اليمين إلى اليسار) والإنجليزية (من اليسار إلى اليمين). التبديل لا يغيّر الأسماء التي أدخلتها ولا يحذفها.

### استخدام العجلة

- اكتب الأسماء أو الصقها في القائمة، اسماً واحداً في كل سطر، أو أضف اسماً من حقل الإدخال.
- اضغط **دوّر العجلة** لاختيار الفائز.
- يمكنك استبعاد كل فائز من السحوبات التالية.
- تظهر أسماء الفائزين كما أُدخلت تماماً، دون ترجمة أو تعديل.

لا توجد أسماء مضمّنة. تبقى الأسماء في الصفحة المفتوحة فقط؛ لا تُرسل إلى خادم وتُمسح عند تحديث الصفحة أو إغلاقها. لا يحتاج التطبيق إلى مكتبات خارجية.

### النشر باستخدام GitHub Pages

1. أضف `index.html` ومجلد `assets/` وملف `.nojekyll` إلى جذر المستودع. أو ضعها داخل `docs/` إذا كان النشر مضبوطاً من ذلك المجلد.
2. افتح **Settings → Pages** في المستودع.
3. ضمن **Build and deployment** اختر **Deploy from a branch**، ثم اختر الفرع `main` والمجلد `/ (root)` (أو `/docs` إذا استخدمت مجلد `docs/`)، ثم احفظ.
4. افتح رابط Pages الذي يعرضه GitHub. غالباً يكون بالشكل `https://USERNAME.github.io/REPOSITORY/`.

إذا اخترت النشر من جذر المستودع، ارفع محتويات الحزمة ليكون `index.html` في الجذر، وليس داخل مجلد `github-pages-wheel`. يحتوي ملف ZIP على مجلد الحزمة لتسهيل النقل؛ فك الضغط ثم انسخ محتويات المجلد. سيعرض GitHub Pages الرابط العام الآمن بعد اكتمال النشر.
